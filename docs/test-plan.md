# 実機テスト手順と結果表

仕様書 `docs/spec.md` §7 のテストケース T-01〜T-12 を 2 台の iPhone で実施するための手順。

## 準備

1. 2 台とも同じビルドをインストールする（README のビルド手順）。
2. 各端末で「曲登録」タブに**別々の曲**を登録する（例: A =「Song A / Artist A」、B =「Song B / Artist B」）。
3. 各端末の「デバッグ」タブで「デバッグログを全削除」を押し、ログを空にする。
4. 「ホーム」タブで「すれ違い通信」をオンにし、Bluetooth の許可を与える。「Central」「Peripheral」が「利用可能」、「スキャン」「広告」が「実行中」になることを確認する。
5. 端末情報（モデル・iOS・低電力モード・ビルド番号）はデバッグ画面の「端末情報」に出る。エクスポートした JSONL の先頭行（`kind: meta`）にも入る。

## 1 試行の手順

1. 2 台を 10 m 以上離す（または片方の通信を一度オフ→オンして状態を初期化する）。
2. 試行条件（下表の A/B の状態）を作る。画面オフは電源ボタンで消灯し、10 秒以上待ってから開始する。
3. 2 台を所定の距離（1 m / 3 m / 5 m）に置き、接近開始時刻をメモする。
4. 所定の接近時間（5 / 15 / 30 / 60 / 180 秒）が経ったら離す。
5. 両端末でアプリを開き、「デバッグ」タブのカウンタとログで次を記録する。
   - `discovered/ok` が出たか（発見）と、接近開始からの秒数
   - `save/ok` が出たか（交換完了）と、発見からの秒数
   - 片側だけ `save/ok` だったか
   - 「履歴」タブに相手の曲が「相互交換」か「受信のみ」で入ったか
6. 同じ相手との再試行はクールダウン（既定 10 分）に引っかかるので、試行を回す間はデバッグ画面でクールダウンを 0 分にする。T-11 だけは 10 分に戻して行う。

## テストケース

| ID | iPhone A | iPhone B | 確認内容 |
|---|---|---|---|
| T-01 | アプリ前面 | アプリ前面 | 発見・双方向交換の基本動作 |

| T-03 | 画面オフ | アプリ前面 | 役割を入れ替え |
| T-04 | 画面オフ | 別アプリを操作中 | 想定ユースケース |
| T-05 | 別アプリを操作中 | 別アプリを操作中 | 両方バックグラウンド・画面点灯 |
| T-06 | 画面オフ | 画面オフ | 理想体験の成立率 |
| T-07 | ロック画面表示中 | 画面オフ | 完全消灯との差 |
| T-08 | 画面オフ | 画面オフ | 1〜5 分滞在 |
| T-09 | OS により終了後の復帰 | アプリ前面 | State Restoration（下記） |
| T-10 | 上スワイプで強制終了 | アプリ前面 | 復帰しないことの記録 |
| T-11 | 同一相手と連続接近 | 任意 | クールダウン 10 分で履歴が増えない |
| T-12 | Bluetooth をオフ | 任意 | UI の案内とエラー処理 |

T-09 の作り方: A の通信をオンにしたまま、他の重いアプリを複数起動してメモリを圧迫するか、長時間放置して OS に終了させる。A のアプリが終了した状態で B を近づけ、A のデバッグログに `restore/info Central 復元` または `Peripheral 復元` が出るかを見る。Xcode からの起動中は OS による終了が起きにくいので、Xcode を切断して行う。

## ログの読み方

デバッグログの `appState` は `active` / `inactive` / `background` で、端末ロック中は末尾に `+locked` が付く。画面オフ条件の試行では、交換時刻のログが `background+locked` になっているかで条件が守られていたかを確認できる。

| eventType | 意味 |
|---|---|
| discovered | Central が相手の広告を受信した（`overflow=true` は相手がバックグラウンド広告） |
| connect | 接続の開始・成功・失敗・スキップ理由 |
| read / write | Central 側の read/write 要求と結果、Peripheral 側の read 応答・write 受信 |
| save | 履歴への保存 |
| cooldown | クールダウンによるスキップ |
| disconnect | セッション終了。`ok 交換完了` か `failed 交換失敗 reason=...` |
| restore | State Restoration による起動 |
| error | タイムアウト・探索失敗など |
